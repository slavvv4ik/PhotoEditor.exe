# PhotoEditor.exe

Приложение для Windows 7/10: прогоняет изображение через 16 методов обработки и автоматически выбирает результат с **наибольшей контрастностью** (стандартное отклонение яркости).

## Возможности

- **Ручной режим**: открыть изображение, запустить обработку всеми 16 методами, посмотреть оценки контраста, сохранить лучший результат.
- **Авто-режим**: при включении приложение следит за папкой `PhotoEditor` на рабочем столе и автоматически обрабатывает все новые/изменённые изображения. Для каждого изображения выбирается вариант с максимальным контрастом и сохраняется в `PhotoEditor\PhotoEditorReady`.
- **16 методов обработки** (из папки `original_methods/`): Порог Отсу, Частотный фильтр, Морфология, Гамма-преобразование, Согласованный фильтр, Пространственный сдвиг, Структурный каркас, Морфологическая скелетизация, Асимметричное выделение, Локальные экстремумы, Бинаризация, Вычитание пост. сост. + окно, LoG/Градиент, Гомоморфная локальная нормализация, Адаптивная бинаризация (биполярная), Сегментация/масштабирование.

## Критерий выбора

Контрастность оценивается как **стандартное отклонение яркости** (`numpy.std`) итогового полутонового изображения. Выбирается метод с максимальным значением.

## Авто-режим

- Входная папка: `C:\Users\<Имя>\Desktop\PhotoEditor`
- Выходная папка: `C:\Users\<Имя>\Desktop\PhotoEditor\PhotoEditorReady`
- Приложение опрашивает входную папку каждые 3 секунды.
- Уже обработанные файлы повторно не обрабатываются, пока не изменятся (по времени/размеру).
- Подпапка `PhotoEditorReady` игнорируется при сканировании входной папки.

## Запуск из исходников

### Требования

- Windows 7 или Windows 10
- Для Windows 7: **Python 3.8.10** (последняя версия с поддержкой Win7)
- Для Windows 10: Python 3.8+ (рекомендуется 3.8–3.11 для совместимости сборки)

### Установка

```bat
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Запуск

```bat
python main.py
```

или двойной клик по `run.bat`.

## Сборка .exe (Windows)

Сборку нужно выполнять **на Windows** в активированном venv:

```bat
build_windows.bat
```

Или вручную:

```bat
pyinstaller --noconfirm --clean --onefile --windowed --name PhotoEditor --hidden-import=PIL._tkinter_finder --collect-submodules methods main.py
```

Готовый файл: `dist\PhotoEditor.exe`.

> Примечание для Windows 7: собирайте exe на машине с Python 3.8.x и зависимостями, совместимыми с Win7. Exe, собранный на Win10 с новыми версиями Python/библиотек, может не запускаться на Win7.

## Структура проекта

```text
PhotoEditorApp/
  main.py                 # GUI + авто-режим
  processor.py            # Запуск всех методов, выбор лучшего по контрасту
  requirements.txt
  build_windows.bat
  run.bat
  methods/                # 16 методов обработки (адаптированы для единого интерфейса)
  original_methods/       # Исходные файлы методов, как были предоставлены
```

## Поддерживаемые форматы

Вход/выход: PNG, JPG/JPEG, BMP, TIFF/TIF, WebP (зависит от сборки OpenCV/Pillow).
